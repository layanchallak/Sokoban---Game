# Sokoban

## 📌 Description

The objective of this project is to develop a **Sokoban puzzle game**. The game consists of moving a player through a grid-based environment and pushing boxes onto their designated targets.

The player must carefully plan each move, as boxes can only be pushed and cannot be pulled back.

## 🎯 Objectives

The game is designed to manage:

* 🎮 Player movement on a grid
* 📦 Box movement and pushing
* 🎯 Target positions for boxes
* 🧱 Walls and obstacles
* 🚫 Collision and movement restrictions
* ✅ Level completion detection
* 🔄 Game state and movement management
